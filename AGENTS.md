# Portfolio Site Guidelines & Rules

## Site Overview & Goals
Personal portfolio website showcasing academic background, skills, and engineering projects hosted via GitHub Pages.

## Core Rules & Design System
- Pure HTML, CSS, and JavaScript only. No frameworks or external libraries.
- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Responsive design targeting mobile and desktop viewports using CSS media queries.
- Primary Color Palette: Modern high-contrast dark theme (Background: `#0f172a`, Text: `#f8fafc`, Accent: `#38bdf8`, Card Background: `#1e293b`).
- Accessibility: All images must have meaningful `alt` text, touch targets >= 44px, proper contrast, and keyboard navigation support (`Tab` / `Shift+Tab`).

## File Map
- `index.html` - Home Page & About Me section
- `projects.html` - Project Showcase (at least 3 detailed projects)
- `skills.html` - Technical & Soft Skills list
- `contact.html` - Contact Form
- `style.css` - Global External Stylesheet
- `script.js` - Interactive JavaScript
